## 功能
- 🚀 **极致简洁**：无广告、无追踪、纯前端
- 🎨 **高度自定义**：壁纸、瓷砖、搜索引擎 可自定义
- 💾 **跨设备无缝**：一键导出/导入 JSON 存档
- 🌍 **中英双语** 自动检测或手动切换

## 技术栈
- Vite + TypeScript
- React
- TailwindCSS + Shadcn
- Zustand + Localforage
- i18n

## 作为 Edge/Chrome 扩展安装（开发者模式）
1. 下载本仓库中 dist 文件夹
2. 打开 Edge → 扩展 → 打开“开发者模式”
3. 点击“加载已解压的扩展程序” → 选择 dist 文件夹
4. 在"来自其他源"中找到本扩展（Home Page 或 主页），点击启用

注意，请关闭其他修改起始页功能的插件，避免冲突。
